Upload Data Stock (DASHBOARD_STOCK)
Upload file Excel (.xlsx) — cukup isi kolom A sampai H:
A: Item Number · B: Site · C: Unit · D: Group · E: Description · F: Description2 · G: Stock Pcs · H: Stock Tonnase
Kolom I dan seterusnya JANGAN diisi — itu rumus yang sudah ada di spreadsheet, otomatis akan ikut terhitung sendiri begitu baris baru masuk. Baris pertama di file harus header (nama kolom), data mulai baris ke-2.
